# SkySheet

一个给 AI 用的轻量 macOS 表格工具：打开 xlsx / csv 看数据，让 Claude Code 通过 MCP 读表、计算贷款和理财的数，
把结果写进新的 sheet，原始数据永远不动。

**状态：设计阶段，还没有可用的版本。** 设计见 [docs/plans/2026-10-08-skysheet-design.md](docs/plans/2026-10-08-skysheet-design.md)。

- macOS 15 起，Apple 芯片
- 零第三方依赖
- 许可证：AGPL-3.0
