# 界面回归小例子

三份文件都是本次自检用 Python 标准库 zipfile 从最小 XML 合成的，没有作者数据。保留成固定样例，是为了让截图前后
使用同一份文件，避免保存器补出的默认样式成为像素比较的变量。

- `merge.xlsx`：A1:C3、E1:E4、A5:C5 合并，锚点四条黑色细边框，冻结首行和首列，覆盖横、纵和双向跨窗格。
- `center.xlsx`：A2、C4、C6 的长文字居中，A/C 列 5 个字符宽、B 列 15 个字符宽，用于看首列被截断和邻列不等宽时的锚点。
- `extent.xlsx`：只有 A1=1，选 AA1、A101、AZ201 时需要扩展画布。

字体 Helvetica 11 磅；其他为空白默认值。居中文字的对称空列、左侧有内容两种额外布局在 `centeredOverflowChecks` 中另行生成并逐像素核对。
