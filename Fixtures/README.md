# 测试样例

## loan.xlsx

- **来源**：作者本人的贷款工作簿（腾讯文档导出的 xlsx），只抽出 Loan 这一张表。2026-10-08 经作者同意公开。
- **处理**：
  - 删掉其余 4 张表，连同它们的文字和图片。xlsx 把所有表的文字放在一张共用的字符串表里，只删表不够，所以这张表也
    重建了：190 条只留 Loan 用到的 46 条，并重新编号。
  - 删掉 O4 备注里一句带银行卡尾号的话。
  - 其余部件按原字节保留。6,952 个单元格里，除 O4 以外，值、公式、样式都和原表逐一相同。
- **用途**：
  1. **公式引擎的对照答案**：124 个公式（RATE、SUM 和四则运算）的缓存值都是腾讯文档算出来的。我们的引擎重算后
     逐个比对：普通公式相对误差不超过 1e-13，RATE 放宽到 1e-9（设计 5.6 节）。
  2. **腾讯文档的怪癖样本**（设计 7.1 节）：`<f>` 里的公式带开头的 `=`；非标准的内置格式编号 60 / 68；`<dimension ref="AG212"/>` 只写一个格子；
     `<c t="s"/>` 没有 `<v>` 的空格子；关系编号从 `rId0` 起；`[Content_Types].xml` 排在 zip 最后；zip 里带目录条目；
     图片同时写了 `r:embed` 和 `r:link`。
  3. **原样保留**：Loan 上挂着一张图片（drawing1 → image1.png，一张还款方式对比表的截图），保存后必须逐字节不变。
- **不能从仓库重新生成**：原始工作簿不在仓库里（`.gitignore` 里的 `/SampleData/`）。要换样例就重新抽一份，照上面
  逐条核对，并确认没有个人信息，再提交。
