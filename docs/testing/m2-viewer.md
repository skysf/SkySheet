# M2 查看器：真机检查清单

> 自检和截图模式够不着的部分（设计第十二节）：真窗口里的鼠标、键盘、滚动，和腾讯文档对照。v0.1.0 起每次发版前走一遍。

## 安装

- [ ] 打开 `dist/SkySheet-0.1.0-arm64.dmg`，把 SkySheet 拖进「应用程序」，从那里打开。
- [ ] 第一次被拦下 →「系统设置 → 隐私与安全性 → 仍要打开」→ 之后正常打开（DMG 里的「首次打开必读」写着）。
- [ ] 直接打开 App（不带文件）只弹「打开」面板，没有空白窗口。

## 打开文件

- [ ] 访达里右键 `Fixtures/loan.xlsx` →「打开方式」→ SkySheet：只出一个窗口，没有多余的「打开」面板。
- [ ] 打开自己的 `SampleData/Housing-Loans.xlsx`：5 个页签都在，点页签能切换。
- [ ] 打开一个银行导出的 csv（GBK 编码）：中文不乱码，账号前面的 0 还在，日期显示成日期，列宽按内容自动放宽。
- [ ] 打开一个有密码的 xlsx、一个老的 .xls：弹出一句英文说明为什么打不开，App 不崩。

## 和腾讯文档对照

把同一个文件在腾讯文档里打开，并排看：

- [ ] 填充色、字体颜色、粗体、边框、居中对齐一样。
- [ ] 数字格式一样：¥ 金额、百分比的小数位数、中文日期。
- [ ] 第一行和 A 列冻结（Loan 表就是这样设的）。
- [ ] 列宽比例差不多；太窄放不下的金额显示 `########`（Excel 也这样）。腾讯文档里显示不一样的格子，记下来。
- [ ] 合并单元格按一整块显示（自己的表格里有合并单元格的那张）。
- [ ] 图片不显示（设计第 11 条），其余内容不受影响。

## 滚动和选区

- [ ] 触控板上下左右滚：冻结的行和列不动，行号列标跟着走，快速滚动时不抖。
- [ ] 点一格选中；按住 Shift 点另一格选一块；拖着选一块，拖出窗口边会自动滚。
- [ ] 方向键移动，Shift + 方向键扩大选区，Tab / 回车往右 / 往下，⌘ + 方向键跳到数据的边上，Page Up / Down 翻页，⌘A 全选。
- [ ] 公式栏：公式格显示「=公式」，数字显示没格式化的原值，日期格显示日期。
- [ ] 选几个数字格：底栏右边显示 Average、Count、Sum，格式跟活动格一样（选 ¥ 列，合计也是 ¥）。

## 其他

- [ ] ⌘C 复制一块，贴到腾讯文档 / Numbers 里还原成表格。
- [ ] ⌘+、⌘−、⌘0 缩放；底栏显示缩放比例。
- [ ] 关掉最后一个窗口，App 还在 Dock 里；点 Dock 图标弹「打开」面板。
