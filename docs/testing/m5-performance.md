# M5 大表格不卡：真机检查清单

> 2026-11-14 的性能改动（设计 8.2 节「性能」、5.5 节）。数字都是在后台量的：测速模式不把窗口放上屏幕，照屏幕上会发生的事
> 自己画进位图（`SkySheet --benchmark …`）；局部重画画得对不对由 `--benchmark-only verify` 逐像素核对，整块重画的样子和改之前
> 的版本逐像素比过。这里列的是只能在真窗口里看的：手感（跟不跟手、卡不卡）和屏幕上会不会留下残影。
> 后台量不到的：真屏幕的合成、触控板惯性滚动的节奏、窗口全屏或外接大屏时一帧要画的面积。
> 2026-11-15 作者装 0.3.4 真机试过，没发现问题。

## 准备

- [ ] 用打包好的 App（release 构建，`VERSION=x.y.z scripts/build-app.sh`）。debug 构建慢得多，手感不作数。
- [ ] 造三张大表（在终端里跑，不弹窗口，几十秒）：
      ```
      .build/arm64-apple-macosx/release/SkySheet --benchmark synthetic:data --benchmark-only none --frames 1 --benchmark-file ~/Desktop/data-100k.xlsx
      .build/arm64-apple-macosx/release/SkySheet --benchmark synthetic:styles --benchmark-only none --frames 1 --benchmark-file ~/Desktop/styles.xlsx
      .build/arm64-apple-macosx/release/SkySheet --benchmark synthetic:formulas --benchmark-only none --frames 1 --benchmark-file ~/Desktop/formulas.xlsx
      ```
      10 万行 × 20 列纯数据、6,500 个合并单元格加各种样式、一万期还款表（5 万个公式）。再拿一份自己平时最大的表格的**副本**。
- [ ] 窗口拉到平时用的大小；有外接大屏的话，在大屏上全屏也走一遍（一帧要画的面积大好几倍）。

## 打开

- [ ] 打开 `data-100k.xlsx`：要等几秒（读 xlsx 本身慢，设计第十五节），出来以后第一屏完整。
- [ ] 打开自己的表：和以前比，出第一屏快了。

## 滚动

- [ ] 触控板、滚轮上下快速滚、左右滚：跟手；冻结的行列、行号列标跟着走，不错位。
- [ ] `styles.xlsx` 上滚动：合并单元格的边框、往旁边溢出的长文字在滚出来的那一条里完整，没有缺一截、没有一条条的缝。
- [ ] 缩放到 137%、75% 再滚一遍（格线不在整像素上时最容易出缝）。

## 移动选区

- [ ] 按住方向键连续走，上下左右都试：选区框跟手，走过的地方不留旧的选区框。
- [ ] 走过合并单元格、冻结线、自动换行的格子、有底色和粗边框的格子：边框、底色、文字都完整。
- [ ] Shift + 方向键、鼠标拖选、点列标行号选整列整行、⌘A：底栏的平均、计数、合计马上出来，数和改之前一样。
- [ ] 10 万行的表 ⌘A：底栏的合计要等一下（后台量的约 0.13 秒，见设计第十五节），之后点一格马上恢复。
- [ ] 缩放到 137% 再按方向键走一遍。

## 改格子

- [ ] 改一格回车：值、底栏合计马上更新。
- [ ] `formulas.xlsx` 改 H1（利率）：整张表跟着重算（约 0.1 秒，设计 5.5 节），没有明显卡顿；⌘Z 回来。
- [ ] 10 万行的表改一格：约 0.1 秒内更新。

## 拖列宽、行高

- [ ] 拖列标、行号之间的边线：跟手，小牌子上的数一直在变；松手以后 ⌘Z 一次回到原来的大小。
- [ ] `formulas.xlsx` 上松手：改工作簿都要整本重算，松手那一下约 0.08 秒（后台量的），看看算不算卡。
- [ ] `styles.xlsx` 上拖行高、Shift + 方向键拉长选区、缩放：后台量的每帧中位数 15–23 毫秒（缩放偶尔 30 多），比一帧
      （16 毫秒）略长，看看手感上能不能察觉（设计 8.2 节「还没到目标的」）。

## 换 sheet、缩放

- [ ] 在几张表之间来回点页签：没有明显停顿。
- [ ] ⌘+ ⌘- 连续缩放：没有明显停顿，每一档画得完整。

## 2026-11-15 的几处修正（Codex 审查）

- [ ] 把一列拖到极窄（几乎看不见）、一行拖到极矮，再点进点出旁边的格子、选中整列整行：列标、行号的字不留旧颜色、
      不缺一块（设计 8.2 节「局部重画的规矩」）。缩放到 137% 再试一遍。
- [ ] 有藏起来的行、里面有自动换行的格子（`styles.xlsx` 第 26 行就是）：左右滚到那一列只露出一部分时，再上下滚，
      格子左下角不出现一团黑块，上一行的第二行字不盖到下一行上。
- [ ] 循环引用：A1 填 `=SUM(B1:C1)`、B1 填 `=A1`、C1 填 `=IFERROR(B1,7)`：三格都显示「循环引用」（#CIRC!），C1 不是 7
      （设计 5.5 节；原来 C1 会显示 7）。
- [ ] 选一列很大和很小的数混在一起的格子（比如 4 个 90000000000000000000、一个 0.000000000000000001、4 个
      -90000000000000000000），底栏的合计和旁边写 `=SUM(…)` 算出来的一样，关掉再打开也一样。

## AI

- [ ] 让 AI 在它的表里写一块（含合并单元格）：淡紫色高亮完整；选区移进移出这一块以后高亮不缺。

## 公式和文件兼容

- [ ] 在真实 Excel / WPS 表中核对「汇总 + SUBTOTAL(109,表1[金额])」、带冒号 / 空白的合计、两行表头、序号后的 B 列合计：
      describe_sheet 和 SQL 不重复加总；不完整 / 跨表 SUM 保留为数据并显示英文提示。
- [ ] 与 Excel 并排核对分数：固定分母 2 / 4 / 8 / 16 / 10 / 100、无整数部分的 ?/2、00/00 的 1.5、
      3.14159 的三位分母约分；0 和 0.01 在 # ?/?、# ??/??、# ??/100 下的空白与对齐也要逐一比。
- [ ] Excel 核对 A2 为 ="" 时 COUNTIF(A1:A4,"<>") 的计数，以及 SUMIF(A:A,"x",B2:B10) 在工作表边界的行为。

## 出问题时

- [ ] 看到残影、缺边框、缝：截屏，记下表格、缩放比例、刚才按了什么。开发时用
      `SkySheet --benchmark 那个文件 --benchmark-only verify` 重现（它把局部重画和整块重画逐像素比，对不上的打印 MISMATCH）。
