## 输入

- [ ] 选中一格直接打字，回车往下、Tab 往右、Shift+回车往上、Shift+Tab 往左；方向键也是提交并移动。（已自动测：打字、回车）
- [ ] 双击一格、或者按 F2：从格子里原来的写法开始改，方向键在文字里移动光标。（已自动测：F2）
- [ ] 中文输入法：选中格子直接打拼音，第一个字母就进输入法（格子里出现带框的拼音），选字后回车提交。
      第一下 Esc 取消拼音，第二下 Esc 取消这次编辑，格子不变。（已自动测）
- [ ] Option+回车在格子里换行。
- [ ] 输 `12%`、`¥1,234.50`、`2025/12/1`、`00123`、`'123`：分别变成百分比、¥ 金额、日期、文字（0 不丢）、文字。
- [ ] 输 `=B2*2` 这样的公式：马上算出结果，依赖它的格子跟着变。（已自动测）
- [ ] 点公式栏改：和格内编辑框是同一份文字；回车提交并往下走，Esc 取消。（已自动测：回车）
- [ ] Delete 键清掉选中格子的内容，格子的底色、边框还在。（已自动测）
- [ ] 合并单元格里打字，存进左上角那一格。

## 撤销、复制、粘贴

- [ ] ⌘Z / ⇧⌘Z 撤销、重做：输入、清除、粘贴、改名、复制 sheet、删 sheet 都能撤；菜单上写着「Undo Typing」之类。（已自动测：输入、删 sheet）
- [ ] 编辑框里按 ⌘Z：取消这次编辑，不动别的。
- [ ] SkySheet 里 ⌘C、⌘V：数字不丢精度，公式的引用按位置平移（A1 的 `=B1*2` 贴到 A5 变成 `=B5*2`）。
- [ ] 选一格复制，选一块粘贴：整块填满。
- [ ] 从腾讯文档 / Excel 复制一块（带中文、带换行的格子）贴进来：行列对得上。
- [ ] SkySheet 里复制一块贴到腾讯文档：还原成表格，显示的是格式化后的样子。
- [ ] ⌘X：复制并清掉（第一版不做「粘贴时才移走」）。

## sheet

## 保存（六道保险）

- [ ] ⌘S：文件只在按了 ⌘S 以后才变（关窗口时选「不存」，文件一个字节都不变）。（已自动测）
- [ ] 第一次 ⌘S 以后，`~/Library/Application Support/ai.skylu.skysheet/Backups/<文件名> (……)/` 里有一份原文件，
      和打开前一字不差；同一次打开里再存不再备份；每个文件最多留 10 份。（已自动测）
- [ ] 打开以后用别的程序改一下这个文件（或者终端里 `touch` 一下），再 ⌘S：弹出「changed by another app」，
      有 Save As…、Overwrite、Reload、Cancel 四个选择；选 Overwrite 先备份别人改过的那一版再存，不会再弹系统自己的提示。（已自动测）
- [ ] 打开 csv、复制出第二张 sheet 再 ⌘S：弹框问「Save as .xlsx…」还是「Save Only “…”」；选前者在旁边存一个同名 xlsx，
      csv 原样不动，窗口改成编辑这个 xlsx。（已自动测）
- [ ] csv 存回去：编码（GBK 的还是 GBK）、分隔符、换行（\r\n 还是 \r\n）不变；日期写成 2025-12-01，百分比写成 5%。（已自动测）
- [ ] File → Revert to Saved：确认以后回到上次存的样子，撤销记录清空。（已自动测）
- [ ] Save As… 的格式下拉里有 xlsx、csv、tsv。

## 崩溃恢复

- [ ] 改几格不存，等半分钟以上，在「活动监视器」里强制退出 SkySheet，再打开：提示「quit before … was saved」，
      选 Restore 出来一个「（Recovered）」窗口，里面是没存的改动；原文件没动。存的时候默认存到原文件旁边。（已自动测）
- [ ] 选 Not Now：下次打开还会问；选 Discard：不再问。
