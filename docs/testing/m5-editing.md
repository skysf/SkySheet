## 宽高

- [ ] 鼠标移到列标两列之间的边线上变成左右拖的样子，行号之间变成上下拖的样子；冻结的 A 列右边那条线也能拖。
- [ ] 拖 B 列的边线：边拖边变，旁边小牌子写「Width: … (… px)」；松手以后 ⌘Z 一次回到原来的宽度。（已自动测）
- [ ] 点 D 列标、Shift 点 F 列标，拖 E 的边线：D、E、F 一起变。（已自动测）
- [ ] 一直拖到 0：这一列藏起来，列标上那里有一道深色的线。（已自动测：藏起来的线）
- [ ] 双击 G 列的边线：宽度刚好放下最长的内容；双击行号下边线同样按内容定高。（已自动测）
- [ ] Format → Column → Width… 输 `abc` 或 `300`：说要 0–255 之间，再弹一次、刚才输的还在。输 `20` 生效。
- [ ] 缩放到 150% 再拖：小牌子上的数字和 100% 时拖到同样大小一样。

## 选中、隐藏、冻结

- [ ] 点列标选中整列（列标加深、加粗），拖着、Shift 点选好几列；点行号同样。表格不跳回第一行。（已自动测）
- [ ] 选着整列在格子上 Shift 点一下：变成一块格子。
- [ ] Format → Column → Hide 藏起 D:F；选 C:G → Unhide 恢复。方向键从 C1 往右直接到 G1。（已自动测）
- [ ] View → Freeze Panes（选中 B2）：冻结第 1 行和 A 列；Freeze Top Row / Freeze First Column 打勾；Unfreeze Panes。（已自动测）
- [ ] ⌘C 复制整列 B，贴到别的软件：只有用到的那些行。

## 格式

- [ ] 选一块，⌘B、⌘I：粗体斜体；再按一次取消。菜单上打着勾。（已自动测：粗体）
- [ ] Format → Number Format 里每一项都试一下，格子显示对；活动格那一项打勾。（已自动测：¥）
- [ ] Text Color、Fill Color 的色板（带小色块）；No Fill、Automatic 回到原样。（已自动测：底色）
- [ ] Alignment 里左中右、上中下；Wrap Text 以后长文字在格子里折行，双击行号边线按折出来的行数定高。
- [ ] 选 A6:C6（有内容）→ Merge Cells：先问「只留 A6，清掉 2 格」，选 Merge 才合并；⌘Z 回来。空的直接合并。（已自动测：弹框文字）
- [ ] 正在格子里打字时，Format 菜单的项是灰的。

## 插删行列

- [ ] Loan 表上 Insert → Insert 1 Row Above：弹框说这张表有图片、不能插删，建议复制一份；什么都没变。（已自动测）
- [ ] 复制 Loan（Sheet → Duplicate Sheet），在副本第 3 行上面插一行：下面的公式点开看，引用都往下挪了，合计还是对的；
      菜单标题随选区变（「Insert 3 Rows Above」「Delete Rows 3–5」）。（已自动测：标题、插删）
- [ ] 副本里删掉第 5 行：引用它的格子显示 #REF!；⌘Z 回来。
- [ ] 在冻结的第 1 行上面插一行：冻结线跟着往下走一行。
- [ ] 插删以后 ⌘S，再用腾讯文档 / Excel 打开：数据、公式、列宽、行高、隐藏、合并、格式、冻结都和 SkySheet 里一样；
      原来那张 Loan 的图片还在原处。
